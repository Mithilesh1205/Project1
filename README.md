# ECE Toolkit ⚡

Hi! This is my first web development project, which I created to make some basic electrical calculations easier for ECE students.

I built this project using HTML, CSS and JavaScript while learning how to develop a website.

## What does this project do?

ECE Toolkit is a simple website that contains different calculators related to electrical and electronics engineering.

Instead of calculating everything manually, we can use these tools to get results quickly.

## Features

### 1. Unit Converter
- Converts voltage between V, mV and kV.
- Converts resistance between ohm, kohm and Mohm.
- Converts frequency between Hz, kHz and MHz.

### 2. Ohm's Law Calculator
- Calculates voltage, current or resistance.
- We need to enter any two values, and the calculator finds the third value.

### 3. Series and Parallel Resistance Calculator
- Calculates the equivalent resistance of resistors connected in series or parallel.
- We can enter multiple resistance values separated by commas.

### 4. Resistor Color Code Calculator
- Calculates the resistance value using four resistor color bands.
- Also shows the tolerance, minimum resistance and maximum resistance.

## Technologies Used

- HTML – To create the structure of the website.

## How I Built It

I started with a basic webpage and gradually added the calculators using JavaScript.

After that, I worked on the design using CSS to give the website a dark theme with neon colors.

I also added functionality to open and close the calculators so that the dashboard stays clean.

While building this project, I learned how HTML, CSS and JavaScript work together to create an interactive website.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Select any calculator and start using it.
